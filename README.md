# Classic Snake Game (p5.js)

 **Snake Game** built using **p5.js** and styled with **Bootstrap 5**.

## 🎮 Features

* **Gameplay:** Navigate the snake, eat food, and grow longer.

* **WASD & Arrow Keys Support.**

* **Smart Food Spawning:** Food will never spawn on top of the snake's body or head.

* **Modern UI:** Clean dark mode grid visual, custom canvas styling, and Bootstrap centering.

## 🕹️ Controls

| Action | Key Controls | 
| ----- | ----- | 
| **Move Up** | `Up Arrow` or `W` | 
| **Move Down** | `Down Arrow` or `S` | 
| **Move Left** | `Left Arrow` or `A` | 
| **Move Right** | `Right Arrow` or `D` | 
| **Restart Game** | Any Arrow Key (when Game Over) | 

## 📁 Project Structure

```
├── index.html     # HTML layout with Bootstrap and p5.js CDN links
├── sketch.js      # Main game loop, canvas setup, rendering & controls
└── snake.js       # Snake class definition (movement, collision, tail tracking)

```
